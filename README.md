# AI-Agent

Консольный агент-программист на Python поверх [Ollama](https://ollama.com). Ведёт диалог на русском языке, умеет вызывать инструменты: выполнять команды оболочки и работать с файлами в рабочем каталоге. Предусмотрен запуск локально и в Docker-контейнере (в том числе с Ollama в отдельном контейнере).

## Возможности

- Список доступных моделей Ollama с отметками возможностей `[thinking]` и `[tools]`, выбор модели при старте.
- Потоковый вывод: отдельно «рассуждения» модели (серым) и ответ.
- Индикатор скорости генерации в заголовке окна консоли (ток/с).
- Цикл вызова инструментов: до 75 раундов на один запрос.
- Выполнение shell-команд в рабочем каталоге агента.
- Файловые операции: чтение, запись, правка, копирование, перемещение, удаление, поиск.
- Длинный вывод инструментов обрезается, чтобы не переполнять контекст модели.

## Требования

- Python 3.10+ (в Docker используется `python:3.12-slim`).
- Запущенный сервер Ollama с моделями, поддерживающими инструменты (tools). По умолчанию используется `qwen2.5-coder:7b`.
- Docker — только для контейнерного запуска.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```bash
python app.py [OLLAMA_HOST]
```

`OLLAMA_HOST` — адрес сервера Ollama, по умолчанию `http://localhost:11434`.

При старте выводится список моделей. Введите номер нужной модели или нажмите Enter, чтобы использовать модель по умолчанию. После трёх неверных вводов подряд программа завершается.

### Команды в чате

| Ввод | Действие |
| --- | --- |
| `/exit`, `/quit`, пустая строка | выход из программы |

## Запуск в Docker

1. Соберите образ:

   ```bash
   docker build -t ai-agent-sandbox .
   ```

2. Создайте сеть для Ollama (один раз):

   ```bash
   docker network create ollama-network
   ```

3. Запустите Ollama в этой сети, например:

   ```bash
   docker run -d --name ollama --network ollama-network -v ollama:/root/.ollama ollama/ollama
   ```

4. Запустите агента (Windows):

   ```cmd
   run.cmd
   ```

`run.cmd` создаёт каталог `data`, монтирует его в `/app/data`, делает его рабочим каталогом агента и подключает контейнер к сети `ollama-network`, где Ollama доступна по адресу `http://ollama:11434`.

Если Ollama запущена на хосте (Docker Desktop), передайте адрес вручную:

```bash
# bash / PowerShell 7
docker run -it --rm -v "${PWD}/data:/app/data" -w /app/data ai-agent-sandbox python /app/app.py http://host.docker.internal:11434
```

Контейнер работает от непривилегированного пользователя `agent`, поэтому команды агента не выполняются от root.

## Инструменты агента

### Системные и командные

| Инструмент | Назначение |
| --- | --- |
| `get_system_time` | Текущие дата и время (ISO 8601 с часовым поясом). |
| `run_shell` | Произвольная shell-команда Linux. |

Ограничения выполнения: таймаут 120 секунд, вывод обрезается до 4000 символов.

В `agent_tools.py` также реализован инструмент `run_powershell` (команды PowerShell в Windows), но в `app.py` он по умолчанию не подключён — агент использует `run_shell`. Чтобы включить его, добавьте `run_powershell` в список `TOOLS` в `app.py`.

### Файловые

| Инструмент | Назначение |
| --- | --- |
| `get_cwd` | Текущий рабочий каталог. |
| `change_directory` | Смена рабочего каталога. |
| `list_files` | Содержимое каталога (до 200 записей). |
| `file_info` | Метаданные файла или каталога. |
| `count_lines` | Количество строк в файле. |
| `read_file` | Чтение файла целиком. |
| `read_lines` | Чтение диапазона строк. |
| `search_file` | Поиск по регулярному выражению в файле. |
| `create_file` | Создание файла. |
| `write_file` | Полная перезапись файла. |
| `replace_text` | Замена фрагмента текста. |
| `append_file` | Дописывание в конец файла. |
| `replace_lines` | Замена диапазона строк. |
| `delete_file` | Удаление файла. |
| `copy_file` | Копирование файла. |
| `move_file` | Перемещение или переименование. |
| `make_directory` | Создание каталога. |
| `remove_directory` | Удаление каталога (опционально рекурсивно). |
| `find_files` | Поиск файлов по маске. |
| `search_in_files` | Поиск по содержимому файлов (до 100 совпадений). |

## Структура проекта

```text
.
├── app.py            # точка входа: выбор модели, чат, цикл вызова инструментов
├── agent_tools.py    # инструменты агента и вспомогательные функции
├── requirements.txt  # зависимости Python
├── Dockerfile        # образ агента
├── run.cmd           # запуск контейнера на Windows
└── data/             # рабочий каталог агента (не хранится в Git)
```

## Безопасность

Агент намеренно не ограничивает команды и файловые операции: он действует с правами своего процесса. Запускайте его в отдельном каталоге или контейнере, не давайте доступ к важным данным и не используйте на общих машинах без изоляции.

## Ограничения

- Поддерживается только сервер Ollama; другие провайдеры LLM не подключены.
- Модель должна поддерживать вызов инструментов, иначе агент будет отвечать только текстом.
- Вывод инструментов обрезается, поэтому очень большие файлы и логи читаются частями.
